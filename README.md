# Formulário de Contato ✉️
Formulário de contato funcional que valida os dados no navegador e no servidor e envia o e-mail.

<img width="1920" height="919" alt="image" src="https://github.com/user-attachments/assets/6b95f55f-f6b3-4a2a-972f-9b2688a0f3ae" />

## Tecnologias
PHP, HTML, CSS, JavaScript/jQuery, jQuery Validate, PHPMailer (via Composer).

## O que faz
- Validação no front-end com jQuery Validate.
- Validação no back-end em PHP.
- Envio de e-mail via PHPMailer.

## Como rodar
1. `composer install`
2. Copie o arquivo de configuração de exemplo e preencha com os dados do seu SMTP.
3. Sirva a pasta com PHP (por exemplo, XAMPP) e abra o formulário no navegador.
